# Next Gen Leader web prototype

## Run locally

In VS Code, open the `web-prototype` folder. Install the **Live Server** extension if needed, then right-click `index.html` and choose **Open with Live Server**.

Open the shown address in a browser. On a phone connected to the same Wi-Fi, replace `localhost` with your computer's local IP address.

## Share online

Upload the contents of this folder to GitHub Pages, Netlify Drop, or Cloudflare Pages. These services provide a normal HTTPS URL. Open it on a phone and use the browser menu's **Add to Home Screen** option to install the PWA.

This is a front-end wellbeing prototype. It does not send chat entries to a server and does not provide real medical care or verified professional booking.
